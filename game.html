    4 · INPUT — intents right now

    What you are asking the game for. Lit means true this instant. newestMoveDirection is the odd one out: it holds the direction you pressed last until UPDATE takes it, which is usually within one step, so it reads null almost always. Press P to freeze the world, then an arrow, and you can see it waiting.

      Newest first. #n says which update tick did it. Three clocks that tick on almost every update — stepCooldown, notice.secondsLeft and runTimer.secondsElapsed — are left out.
